# Sexually-Transmitted-Infections-Global-analysis-dashboard
Interactive power BI dashboard analyzing global trends in sexually transmitted infections to provide insights for public health decision-making
## Diseases
HIV
SYPHILIS
HPV
HEPATITIS B
## Objectives
Identify the most prevalent STI across different regions
Compare STI cases across countries and regions
Analyze total cases and death over time
Identify regions with higher disease burden
## Tools used
Microsoft Exce
Power BI
## Key Insights
The dashboard provides interactive visualization that allows users to explore STI trends by disease, country, and region.
